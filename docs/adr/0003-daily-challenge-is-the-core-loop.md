# The Daily Challenge is the core loop, modeled on LinkedIn Games

Every Stack releases one numbered Daily Challenge a Day: three Questions, the same for every Learner, with only the first try scored. Learners keep a Streak for each Stack by playing that Day's Challenge, can share a Result Card, and can play any past Challenge from the Archive. The Lesson path stays as a second mode for Learners who want guided study. We chose this over making the Lesson path, with a required Daily Review, the only daily habit, because a short shared puzzle is a habit people keep, and an Archive lets late joiners catch up on everything the Stack has covered.

## Consequences

- A Learner can have any number of Active Stacks; each has its own Challenges, Lesson path and Streak.
- Daily Review is replaced by an optional Review with no rounds, timers or blocking. Lessons are gated only by completion.
- A Streak counts only Daily Challenges played on their own Day. Archive plays and Review never extend it.
- A Daily Challenge the Learner never played creates no Missed Questions. Catch-up is optional.
- Any Challenge can be replayed for learning. A replay never changes the score, the Streak or Missed Questions.
- If grading a written answer fails, the Learner can resubmit for feedback, but that Question earns no point toward the Challenge score.
- Released Challenges are frozen, so a Challenge Question can't be fixed in place. It is retired instead (see ADR 0004).
- No leaderboards or timers in version 1; the Result Card is the only social feature.
