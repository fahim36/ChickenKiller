# web

The Next.js 16 front end. Server components fetch from the FastAPI backend at `API_URL`, which defaults to `http://localhost:8000`. See the [root README](../README.md) for how to run the whole app.

| Command | What it does |
|---|---|
| `npm run dev` | Dev server on http://localhost:3000 |
| `npm test` | Vitest unit and component tests |
| `npm run lint` | ESLint |
| `npm run build` | Production build, including the type check |
